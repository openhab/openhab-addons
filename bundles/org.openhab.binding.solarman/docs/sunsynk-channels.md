# Sunsynk register catalog

Generated from the pinned kellerza/sunsynk definitions. Addresses are decimal, zero-based holding registers. Ordered tuples preserve low-word-first significance; aliases are included. Limits may reference another sensor ID. Constant and PVDynamicTotalSensor tuples can contain virtual placeholders such as [0]; these are not direct measurement addresses or additional read requests. MathSensor tuples identify calculation inputs. The three single-phase identification/version channels are separately attributed binding additions from deye_hybrid; other labels and options come from the pinned profile. See README for installation, command types and profile selection.
